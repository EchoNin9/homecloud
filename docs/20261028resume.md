## Design notes worth knowing

Everything in `docs/20261027resume.md` "Design notes" still holds, plus:

- **Arrange mode styles** key off `section[data-arranging]` and `.hc-tile[data-arranging]`. The dragged
  tile gets `data-dragging`, set directly on the element in `onDragStart` and removed in `onDragEnd`
  (no re-render). The filled button style is `.hc-chip-btn.hc-chip-primary`.
- **`.hc-sr` (visually hidden) is `position: absolute`.** Inside a horizontal scroller with no positioned
  ancestor, it's placed against the page and widens it: that was the phone sideways scroll. Give the
  scroller `position: relative` (`.hc-badges` has it now). Check for this when adding `.hc-sr` text.
- To test phone widths when the Chrome window won't shrink: load the app in a 390px (and 320px) `<iframe>`
  on the same origin and measure `document.documentElement.scrollWidth` against `innerWidth`.
