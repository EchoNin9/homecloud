## Gotchas found (already fixed/documented)

- DSM's kernel lacks seccomp, so BuildKit builds fail. Build the bridge with
  `sudo DOCKER_BUILDKIT=0 docker build -t homecloud-bridge:0.1.0 bridge`, then
  `docker compose up -d --no-build bridge` (see `docs/synology.md`).
- The ingest Lambda dropped `status` messages (no `v` field per contract). Fixed in `6b56491`.
- The `!` prefix in Claude Code has no TTY, so `sudo` password prompts over ssh fail there.

## Redeploy recipes

```sh
# web (build, upload with cache headers, invalidate CloudFront)
AWS_PROFILE=echo9 ./scripts/deploy-web.sh

# cloud code (lambdas): plan, review, apply the plan
tofu plan -out=tfplan && tofu apply tfplan

# bridge after code changes: copy nas/bridge to the NAS, rebuild with the legacy builder, restart
tar -C nas -czf - bridge | ssh -i ~/.ssh/nas2 admin@<nas2-ip> 'tar -C /volume1/docker/homecloud/stack -xzf - && \
  cd /volume1/docker/homecloud/stack && sudo DOCKER_BUILDKIT=0 /usr/local/bin/docker build -t homecloud-bridge:0.1.0 bridge && \
  sudo /usr/local/bin/docker compose up -d --no-build bridge'
```
