## Moving to a new machine

| Need | Used for | How to get it on the new machine |
|---|---|---|
| `gh` login | PRs, CI, repo vars | `gh auth login` |
| NAS ssh key (`~/.ssh/nas2`, ed25519) | bridge rebuilds, NAS checks | Copy it from the old Mac by a private channel. Or make a new key and add the `.pub` to `admin`'s `~/.ssh/authorized_keys` on the NAS (DSM → Users → admin) |
| AWS profile `echo9`, `us-east-1` | manual `tofu` plan/apply, bootstrap changes, S3 backups | Create a **new** access key in IAM, then `aws configure --profile echo9`. Deactivate the old key (see Security) |
| `tofu` ≥ 1.10 (1.12 used), Node 20, Python 3.12+ | local tests and plans | Homebrew: `opentofu node python` |
| Gitignored tofu files | any local `tofu` run | Restore from S3 (below) |
| Device `private.key` | only for re-provisioning the cert | Not needed day to day. It lives on the old Mac (`examples/standalone/certs/`) and on the NAS (`bridge/certs/`). It isn't in S3 or git, so leave it there |

Restore the gitignored tofu files (both `terraform.tfvars`, `backend.hcl`,
`backend_override.tf`, `home.csr`). They're backed up under `local-files/` in the state bucket:

```sh
export AWS_PROFILE=echo9 AWS_REGION=us-east-1
aws s3 cp --recursive s3://homecloud-tofu/homecloud/local-files/ cloud/terraform/
cd cloud/terraform/examples/standalone && tofu init -backend-config=backend.hcl && tofu plan
# MUST say "No changes". Any aws_iot_certificate change means the CSR tfvars is wrong: stop.
```

After editing any gitignored file, push it back with `aws s3 cp <file> s3://homecloud-tofu/homecloud/local-files/<same path> --sse AES256`.

## Auto-deploy (new today)

- `.github/workflows/deploy.yml` runs on push to `main` when `cloud/**`, `web/**`,
  `scripts/deploy-web.sh` or the workflow change. Markdown, `cloud/tests`, `web/mock` and
  `*.test.ts` don't trigger it. It can also be run by hand (`workflow_dispatch`).
- What it does:
  1. Assumes the role `github-actions-homecloud-deploy` through OIDC.
  2. Pulls `terraform.tfvars` + `backend.hcl` from the `local-files/` S3 prefix.
  3. Runs `tofu plan`. A jq guard **refuses** any delete of `aws_iot_certificate`,
     `aws_dynamodb_table` or `aws_cognito_user_pool`.
  4. Runs `tofu apply`, then `scripts/deploy-web.sh`.
- The role is defined in `cloud/terraform/bootstrap/github-deploy.tf`. The repo uses GitHub's
  **immutable OIDC subjects**, so the trust policy uses `github_sub_prefix` (see
  `docs/first-deploy.md` step 9). Repo variables: `AWS_DEPLOY_ROLE_ARN`, `TOFU_STATE_BUCKET`.
- Watch runs with `gh run list -w deploy.yml`. The last three (#24, #26, #28) succeeded.
- IAM/bootstrap changes: the agent's auto mode blocks IAM applies and S3 uploads of sensitive
  files. Write a script and have the owner run it with `! bash <script>`. `!` has no TTY, so
  don't use `read -p`. Apply a saved `tfplan` instead.

## What was built (web: `web/src/components/`)

- **Organize** (`util.ts` `organize()`):
  - Sort: name / recently changed.
  - Group: by type, by area (HA areas via the bridge's `homecloud_area`), My Groups (custom,
    named), or none.
  - Favourites always come first. Hidden entities move to a "Hidden" section when "Show hidden"
    is on.
  - Prefs are stored per home in `localStorage` `hc.prefs.<homeId>`.
- **Select mode:** a sticky bulk bar for 250+ devices. Select all shown, add to/remove from a
  group, favourite, hide, unhide.
- **Warnings row:** red chip when a door has been open ≥ 5 min. Pink chip when a drive is above
  50 °C (`sensor.*_drive_N_temperature`). Clicking a chip scrolls to the card.
- **Top bar:** ☀ sunrise / ☾ sunset for **today** in 24h time. It's computed in the browser from
  `sun.sun`'s `homecloud_latitude`/`homecloud_longitude` and rolls over at midnight.
- **Slide-out nav (☰), with collapsible shades** whose state is kept in `sessionStorage`
  `hc.shade.<id>`:
  - On this page
  - Saved Queries (max 15)
  - Groups → My Groups (jump, rename ✎, delete ×) / HA Groups (None, By type, By area,
    Recently changed)
- **Design-critique pass:**
  - Card footers and entity ids show only in select mode.
  - Read-only sensors use compact one-row tiles. Cards that are on get a tint.
  - 44px touch targets on coarse pointers. Two-column grid at ≤600px.
- Local dev with mock data: `cd web && npx vite --mode mock`. Mock data is in `web/mock/mockApi.ts`.
  `npm run dev:mock` fails if run from the repo root.

Bridge (`nas/bridge`): `ha.get_areas()` / `ha.get_location()` are refreshed every snapshot.
`filters.export(state, extra)` adds the extra attributes after the 4KB cap. Both are documented
in `docs/contract.md`.
