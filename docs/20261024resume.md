## Agent tips from these sessions

- Auto mode blocks IAM applies, `git push` to `main`, and S3 uploads of sensitive files. Write a
  script to the scratchpad and have the owner run `! bash <script>`. `!` has no TTY, so apply a
  saved `tfplan` rather than prompting.
- Before any `tofu apply`, the plan must show no `aws_iot_certificate` change. Otherwise the NAS
  bridge disconnects. Auto-deploy has a guard for this, but manual applies don't.
- macOS `sed` has no `I` flag. Redact secrets with a fixed pattern, or better, never `grep`
  credential files at all.
- DynamoDB keys are `PK`/`SK` (uppercase). Example: `PK=HOME#home, SK=META`.
